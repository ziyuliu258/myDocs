## 概念
### Skill
一个Skill的基本组织方式可以如下（以一个CAD Skill的组织为例）：
```
cad-articulated/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── references/
│   ├── articulation-model.md
│   ├── step-urdf-bridge.md
│   ├── validation-rules.md
│   └── export-formats.md
├── scripts/
│   ├── compile_model.py
│   ├── validate_geometry.py
│   └── export_urdf.py
└── assets/
    └── example_models/
```
其中：
- `SKILL.md`：说明什么时候使用，以及 Agent 应遵守的核心规则；
- `references/`：放 Articraft、URDF、STEP、关节语义等详细知识；
- `scripts/`：放确定性的编译、检查、导出工具；
- `agents/openai.yaml`：配置 Codex 中的显示名称和简介；
- `assets/`：放样例 CAD、模板和测试输入。
