# 第 2 部分：第 4–7 节

## 4　Articraft-10K

我们使用 Articraft 构建了 Articraft-10K：一个经过人工筛选、包含超过 1 万个可动 3D 模型的大型数据集（图 1、图 4）。Articraft-10K 包含 245 个物体类别；我们进一步将其映射为 15 个大类，并在图 11a 中结合词云进行可视化。每个资产均附带一个 URDF 文件、对应的 `model.py`，以及 agent 的完整轨迹记录（包括推理、反馈和工具使用；示例见图 2 与附录）。未来，这些轨迹可用于通过监督微调后训练开源语言模型，从而有望缩小开源模型与闭源模型在 3D 生成方面的差距。

**图 4：** Articraft 生成的 Articraft-10K 数据集中可动 3D 资产示例。图中列为“文本提示—可动资产—部件可视化”；示例提示包括“黑色轮椅”“键盘”“三脚架上的望远镜”“带控制旋钮的箱式风扇”“带轮子的塔式起重机”和“基座上的卫星天线”。

**图 5：** 不同方法生成可动资产的对比。图中提示为“咖啡机”和“带镜头的相机”，比较了 PhysX-Anything、URDF-Anything、Articulate-Anything、Vanilla Codex、Articraft（GPT-5.4）与 Articraft（GPT-5.5）。

**数据集构建。** 为构建 Articraft-10K，我们首先挑选了一大批模型能够良好生成的物体类别。具体而言，我们先通过人工编写提示词来探索 agent 的能力；通过分析成功和失败案例，制定了用于识别潜在适用类别的准则；再将这些准则交给 LLM，让其提出新的类别，随后由人工进行审核和筛选。通过这一过程，我们确定了 245 个合适的类别，例如华夫饼机、无人机、固定式健身车、立式搅拌机、安装在三脚架上的设备，以及带铰链盖的缝纫盒。

接着，我们又制定了准则，让 LLM 为每个类别生成提示词；这一过程同样考虑了 agent 的能力和局限。随后，将这些提示词交给 Articraft agent，以生成 Articraft-10K。典型失败案例见第 B.5 节和图 18。

我们还通过人工评分流程进一步筛选生成资产。每个生成物体依据三项标准获得 1 至 5 分：（1）整体几何及各个组成部件的真实感；（2）应当存在可动运动的位置是否确实具有相应运动；（3）关节运动是否遵守基本物理约束，例如不存在悬浮连杆或不合理的运动。对于每一项较轻微的违反，均从初始 5 分中扣除 1 分。对任一标准存在严重违反、或最终得分低于 4 分的物体，均被排除出数据集。在 GPT-5.4、GPT-5.5 与 Gemini 3.1 Pro 的生成运行中，10,909 个生成资产中有 10,018 个通过该筛选，整体保留率为 **91.8%**。更多细节见第 A.2 节。

**实验细节。** 与所有生成任务一样，很难定义好的自动化指标，因此我们主要依赖用户研究来评估生成质量。为此，我们从 PartNet-Mobility [55] 的 46 个类别构建了一个基准提示集，并为每个类别编写 5 条提示。随后，我们利用 [12] 为每条基准提示生成一张参考图，作为图像条件方法（即 PhysX-Anything 与 URDF-Anything+）的输入。对于 Codex，我们要求它以 URDF 格式生成文本提示所描述的可动资产，并向其提供全部编程工具和网页搜索工具。

为评估生成资产的质量，我们以随机顺序向参与者展示文本提示，以及六种竞争方法（包括我们方法的两个变体）生成的 3D 资产。这项感知研究覆盖 125 名具有不同学术背景的非专业大学生；每名参与者评估约 40 个随机分配的物体，共收集 5,000 次比较。参与者被要求基于提示一致性和总体质量，从六个结果中选出并排序最好的三个。

**结果。** 用户研究结果汇总于图 6。一个关键比较是单独使用 GPT-5.5 与使用相同底层 LLM 的 Articraft 之间的差异。差异十分显著：单独使用 GPT-5.5 的结果排名倒数第二。这表明，为 LLM 提供领域专用编程接口和 harness 会带来显著效果。图 5 给出了视觉对比；补充网站中还提供了更多示例。

**图 6：** 用户研究结果。图例为“第 1 名（Top 1）”“第 2 名（Top 2）”“第 3 名（Top 3）”和“未进前三（Not top-3）”。图中标出的比例包括：Articraft（GPT-5.5）为 42%、28%、14%；Articraft（GPT-5.4）为 26%、37%、18%；Articulate-Anything 为 10%、13%、26%；PhysX-Anything 标出 10% 与 16%；Codex（GPT-5.5）标出 15%；URDF-Anything+ 标出 10%。

**对 LLM 的消融实验。** Articraft 可以使用任意具备编程能力的 LLM。在图 7 中，我们针对相同的可动无人机提示，比较了 OpenAI GPT-5.5 [41]、Google Gemini 3.1 Pro [12] 和 Anthropic Claude Opus 4.7 [2]，并将所有模型设为高推理强度。所有模型都恢复出了所需的运动学结构，但 GPT-5.5 生成了更多视觉细节，而 Gemini 和 Claude 生成的几何更为简单。

我们还改变了 GPT-5.5 的推理强度。低、中、高三种强度分别以 **39、51 和 78 个视觉元素**生成了相同的目标结构，这表明，在该说明性示例中，推理强度主要增加的是几何与表面细节。精确提示和运行统计见第 B.4 节。

**重建真实场景。** 我们利用 agent 可由图像提示的能力，遵循 LiteReality [14] 管线执行完整房间重建。首先，我们从 iPhone RoomPlan 的室内采集结果出发；该系统提供每个物体的 3D 位置、朝向和尺度。系统会自动提取每件家具的裁剪参考图，并用其提示 Articraft 生成对应的可动物体。随后，我们应用材质绘制阶段（第 3.3 节）恢复基于物理渲染（PBR）的材质，并将生成资产装配到解析得到的场景布局中，以进行房间重建。最终场景（图 8）既忠实于原始采集结果，又增加了可动性，因此可用于交互和仿真。

**图 8：** Articraft 的图像条件生成结果。给定一张参考图，Articraft 会生成一个完整可动的 3D 资产（左）。与 LiteReality [14] 集成后，它还能够由室内扫描实现具有可动结构的房间级重建（右）。更多结果见补充网站。

**图 9：** Articraft 生成的可动 3D 资产可以直接导入物理模拟器，并由机械臂和 VR 头显进行操控。

## 6　评估 Articraft-10K 数据集

在验证了 agent 后，我们接下来评估新的 Articraft-10K 数据集作为训练数据及在应用中的有效性。

**训练前馈式 3D 物体关节结构模型。** 我们考察了 Particulate [22]：这是一个近期提出的、以 Transformer 为基础的模型；它以单个 3D 网格为输入，预测 3D 部件、运动学结构和关节参数。如表 3 所示，用 Articraft-10K 增强其训练数据（即 PartNet-Mobility [55] 和 GRScenes [50]）能够提升其性能。这说明，我们的 agent 所生成的数据能有效训练此类模型。表 6 给出了逐类别结果，表明 Articraft-10K 对原始训练分布之外类别带来的提升尤为显著。

**在机器人仿真中使用 Articraft-10K。** 我们将 Articraft-10K 的资产部署到 NVIDIA Isaac Sim [35] 环境中。对于每个物体，我们为选定部件定义一条目标轨迹，随后使用标准逆运动学控制机器人末端执行器与生成物体交互；例如，使用 Franka 机械臂拉开一个抽屉（示例见图 9）。一次成功交互说明，该物体不仅在视觉上可信，还具有适用于仿真的有效可动结构。更多结果见补充网站。

**虚拟现实。** 我们还将 Articraft-10K 的资产部署到虚拟现实（VR）环境中（图 9）。我们模拟用户双手与物体之间的交互。检测到碰撞后，自定义脚本会控制 URDF 模型中定义的关节运动。如补充网站所示，最终交互自然且真实。

## 7　结论

我们提出了 Articraft：一个可扩展生成可动 3D 资产的 agent 系统。通过将任务专用 SDK 与受限执行 harness 配对，Articraft 将可动资产创建转化为一个以验证和几何反馈为基础的“编辑—执行—修复”循环，而无需依赖渲染图像的视觉检查。借助这一 agent 系统，我们构建了 Articraft-10K：一个包含超过 1 万个高质量可动 3D 资产的大规模数据集，提供源程序、语义部件结构、关节规格和生成轨迹。我们的结果表明，领域专用的编程接口和执行 harness 是实现可扩展、稳健的可动资产生成的关键要素，并能支持前馈模型训练、仿真和 VR 交互等下游应用。
