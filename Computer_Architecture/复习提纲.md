## 1. 第 1 章：计算机系统结构的基础知识

### 考试定位

今年参考分布约 15 分，其中含名词解释、填空、简答和计算。第 1 章最重要的是“性能怎么度量、怎么比较、怎么改进”。作业讲解中的 `1.11` 明确说明 CPI/性能改进是重点。

### 必会概念

- 计算机系统结构、计算机组成、计算机实现三者区别。
- ISA 是软件和硬件之间的接口。
- Flynn 分类：SISD、SIMD、MISD、MIMD。
- 响应时间、吞吐率、执行时间、性能的关系。
- Amdahl 定律和局部优化的收益上限。
- CPU 性能公式与加权 CPI。
- 性能测试与平均方法：算术平均、加权平均、调和平均、几何平均。

### 必会公式

```text
性能 = 1 / 执行时间
加速比 = 改进前执行时间 / 改进后执行时间
CPU 时间 = IC × CPI × 时钟周期时间
CPI = Σ(指令比例_i × CPI_i)
Amdahl: S = 1 / ((1 - f) + f / s)
```

### 必会题型

- 给出各类指令比例和 CPI，计算平均 CPI 与 CPU 时间。
- 给出某部件可改进比例和部件加速比，计算总体加速比。
- 给出总体加速比和部件加速比，反推可改进比例。
- 比较两种设计方案的性能收益。
- 判断“优化某一部分是否值得”，说明 Amdahl 限制。

### 易错点

- 题目中“某类指令占比”和“该类中某子类占比”不能重复扣减。
- CPI 是加权平均，不是简单平均。
- 性能与执行时间成反比，说“性能提高 n 倍”要换成执行时间比值。

## 2. 第 2 章：指令系统的设计

### 考试定位

今年参考分布约 8 分，以填空和简答为主。重点是 ISA 分类、寻址方式、RISC/CISC、指令格式和编码思想。计算题可能性较低，但操作码编码和平均码长需要会。

### 必会概念

- ISA 包含程序员可见的指令集合和机器状态。
- 操作数存放位置：堆栈、累加器、通用寄存器。
- 通用寄存器结构：寄存器-存储器型 RM、寄存器-寄存器型 RR，也称 Load/Store。
- 显式操作数与隐式操作数。
- 寻址方式、有效地址、字节编址。
- 大端、小端、边界对齐。
- 指令格式、操作码编码、扩展操作码、哈夫曼编码思想。
- CISC 和 RISC 的设计思想、优缺点。
- MIPS 指令系统的基本特征：Load/Store、三操作数、固定长度等。

### 必会题型

- 给表达式，分别写堆栈型、累加器型、RM 型、RR 型代码。
- 比较 CISC 和 RISC。
- 判断某个属性是否属于 ISA。
- 解释大端/小端和对齐问题。
- 根据指令频率设计操作码或计算平均码长。

### 易错点

- ISA 不等于实现；“是否有乘法指令”属于体系结构，“用什么硬件实现乘法”属于组成。
- RISC 的 IC 可能比 CISC 多，但 CPI 和时钟周期可能显著更小。
- Load/Store 结构中 ALU 指令不直接访问存储器。

## 3. 第 3 章：流水线技术

### 考试定位

今年参考分布约 18 分，其中计算题约 12 分，是核心章节。第 2 次作业和作业讲解中的 `3.12` 都指向流水线性能、相关与冲突、控制相关处理。

### 必会概念

- 流水线、流水线级/段、流水线深度、流水寄存器。
- 吞吐率、最大吞吐率、加速比、效率。
- 先行控制：缓冲技术 + 预处理技术。
- 结构相关、数据相关、控制相关。
- RAW、WAR、WAW。
- 定向/旁路、流水线互锁、load-use 停顿。
- 控制相关处理：清空/冻结、预测成功、预测失败、延迟分支。
- 非线性流水线：预约表、禁止表、冲突向量、状态转换图、最优调度。
- MIPS 五段流水线：IF、ID、EX、MEM、WB。

### 必会公式

```text
等时段 k 级流水线处理 n 个任务:
T = (k + n - 1)Δt

吞吐率:
TP = n / T

最大吞吐率:
TPmax = 1 / 瓶颈段时间

加速比:
S = 串行执行时间 / 流水执行时间

效率:
E = S / k

实际 CPI:
CPI = 理想 CPI + 结构冲突停顿 + 数据冲突停顿 + 控制冲突停顿
```

### 必会题型

- 画流水线时空图，计算执行时间、吞吐率、加速比、效率。
- 分析结构冲突、数据冲突、控制冲突。
- 判断 RAW/WAR/WAW，并说明能否用 forwarding 解决。
- 控制相关 CPI 计算：清空流水线、预测成功、预测失败。
- 从预约表求禁止表、冲突向量、状态转换图和最优调度。

### 易错点

- 流水线一般提高吞吐率，不一定减少单条指令延迟。
- 控制相关题必须先判断目标地址何时得到、分支条件何时得到。
- 非线性流水线中“禁止表”来自同一行任意两个使用时刻的距离。
- 等间隔调度不一定最优；最优调度常来自状态图中的闭合回路。

## 4. 第 4 章：向量处理机

### 考试定位

今年参考分布约 8 分，其中可能有计算。第 4 章内容相对独立，适合通过概念表和公式题快速拿分。

### 必会概念

- 向量处理机与标量处理机。
- 横向处理、纵向处理、纵横/分组处理。
- 存储器-存储器型向量机、寄存器-寄存器型向量机。
- 向量寄存器、标量寄存器、快速暂存器、向量屏蔽寄存器。
- Vi 冲突、功能部件冲突。
- 多功能部件并行、链接技术、分段开采。
- 编队、chime、向量指令处理时间、峰值性能、半性能向量长度、向量长度临界值。

### 必会公式与方法

```text
向量指令处理时间:
Tvp = Ts + Tvf + (n - 1)Tc

无瓶颈且按时钟周期计:
Tvp ≈ Tstart + n

向量序列执行时间:
Tv = Σ(各编队启动时间 + 向量长度相关时间)

峰值性能:
R∞ = lim(n->∞) 浮点运算次数 / 执行时间
```

### 必会题型

- 比较横向、纵向、纵横处理方式的数据相关和功能切换次数。
- 判断几条向量指令能分成几个编队。
- 计算链接与非链接执行时间。
- 处理向量长度超过向量寄存器长度时的分段开采。
- 计算峰值性能、半性能向量长度或临界向量长度。

### 易错点

- 链接要求无向量寄存器使用冲突、无功能部件冲突、向量长度相等。
- 分段开采时，余数段也要单独处理。
- 一个编队内的向量指令必须能在同一时钟周期一起开始，不能有资源冲突。

## 5. 第 5 章：指令级并行

### 考试定位

今年参考分布约 17 分，简答和计算都可能出现。第 3 次作业直接考记分牌和 Tomasulo，因此这是第 5 章的核心。

### 必会概念

- 指令级并行 ILP、IPC、基本块、循环级并行。
- 相关与冲突的区别：相关是程序属性，冲突是流水线属性。
- 数据相关、名相关、控制相关。
- RAW、WAR、WAW。
- 静态调度、动态调度。
- 寄存器重命名。
- 记分牌算法：集中控制、功能部件状态表、寄存器结果状态表。
- Tomasulo 算法：保留站、CDB、分布式控制、寄存器换名。
- BHT、两位分支预测、相关分支预测、BTB。
- 前瞻执行、ROB、精确异常。
- 多指令流出、超标量、超流水线、VLIW。

### 记分牌算法要点

```text
四阶段：流出 -> 读操作数 -> 执行 -> 写结果
流出：检查结构冲突和 WAW
读操作数：等待 RAW 消除
执行：功能部件执行
写结果：检查 WAR 后写回
```

### Tomasulo 算法要点

```text
三阶段：流出 -> 执行 -> 写结果
流出：分配保留站，记录操作数值 Vj/Vk 或生产者 Qj/Qk
执行：两个操作数就绪后执行
写结果：通过 CDB 广播，等待者同时获得结果
```

### 必会题型

- 判断指令序列中的 RAW/WAR/WAW。
- 根据功能部件延迟，推进记分牌状态表。
- 根据保留站、CDB、寄存器结果状态，推进 Tomasulo。
- 比较记分牌和 Tomasulo 为什么后者通常更快。
- 分析 BHT、BTB 的作用和区别。
- 简述 ROB 如何支持前瞻执行和精确异常。

### 易错点

- Tomasulo 中 WAR/WAW 通过保留站/重命名消除，RAW 仍要等待数据。
- CDB 只有一条时，多个结果不能同一周期广播。
- BTB 存分支目标地址；BHT 存分支历史/方向预测。
- 前瞻执行的结果先进入 ROB，提交时才更新体系结构状态。

## 6. 第 6 章：指令级并行的开发——软件方法

### 考试定位

今年参考分布约 6 分，计算题可能性低，但与第 5 章联动。重点是循环展开、指令调度和 VLIW。

### 必会概念

- 基本指令调度。
- 循环展开、寄存器重命名、指令调度。
- 跨基本块的静态调度。
- 分支延迟槽调度：从前调度、从目标处调度、从失败处调度。
- 全局调度、踪迹调度、超块调度。
- 静态多指令流出、VLIW、静态超标量。

### 必会方法

循环展开做题步骤：

1. 复制循环体若干次。
2. 为不同迭代使用不同寄存器，避免名相关。
3. 删除多余的循环控制指令。
4. 调整偏移量和循环边界。
5. 将无关的 load、计算、store 重新排序，填补延迟槽。
6. 检查存储器访问是否真的相互独立。

### 必会题型

- 给循环代码，展开 3 次或 4 次并调度。
- 比较调度前后每个元素平均周期数。
- 说明循环展开的正确性条件。
- 简述 VLIW 的优点和不足。

### 易错点

- 展开后 store 的地址偏移量最容易错。
- 使用同一个寄存器会制造新的名相关。
- 不是所有循环都能安全展开，必须检查跨迭代数据相关。

## 7. 第 7 章：存储系统

### 考试定位

今年参考分布约 19 分，其中计算题约 13 分，是最高优先级章节。Cache、AMAT、TLB、页表、多体交叉都要会。

### 必会概念

- 存储层次结构：寄存器、Cache、主存、磁盘。
- 时间局部性、空间局部性。
- 命中率、不命中率、命中时间、不命中开销、AMAT。
- Cache 映像：全相联、直接映像、组相联。
- 替换算法：LRU、FIFO、Random。
- 写策略：写直达、写回；写分配、不写分配。
- 3C 失效：强制性、容量、冲突。
- 降低不命中率：增大块、增大容量、提高相联度、Victim Cache、伪相联、预取、编译器优化。
- 减少不命中开销：两级 Cache、读不命中优先于写、关键字优先/提前重启动、非阻塞 Cache。
- 减少命中时间：小而简单的 Cache、虚拟 Cache、VIPT、流水化 Cache、踪迹 Cache。
- 并行主存：单体多字、宽主存、多体交叉。
- 虚拟存储器：页式/段式、页表、TLB、PTE、多级页表。

### 必会公式

```text
AMAT = 命中时间 + 不命中率 × 不命中开销
存储器停顿周期 = 访存次数 × 不命中率 × 不命中开销
实际 CPI = 理想 CPI + 每条指令平均访存停顿周期

两级 Cache:
AMAT = L1 命中时间 + L1 不命中率 × (L2 命中时间 + L2 局部不命中率 × L2 不命中开销)
L2 全局不命中率 = L1 不命中率 × L2 局部不命中率

VIPT 限制:
Cache 容量 <= 页大小 × 相联度
```

### 地址划分题

```text
块内偏移位数 = log2(块大小)
组数 = Cache 容量 / (块大小 × 相联度)
索引位数 = log2(组数)
标识位数 = 地址总位数 - 索引位数 - 块内偏移位数
```

### 必会题型

- AMAT、CPI、访存停顿周期。
- 两级 Cache 局部/全局不命中率。
- 直接映像/组相联地址划分。
- LRU 替换过程。
- 判断 3C 失效类型。
- 比较增加块大小、容量、相联度的影响。
- 多体交叉存储器的编址和体冲突。
- 页表/TLB、多级页表页数计算。

### 易错点

- L2 的局部不命中率不是全局不命中率。
- 块变大可能降低强制不命中，但也可能增加冲突不命中。
- 虚拟 Cache 有同义/别名问题。
- TLB 是页表项的缓存，不是数据 Cache。
- 页内偏移位数由页大小决定，虚页号/物理页帧号由地址位数扣除页内偏移得到。

## 8. 第 8 章：输入/输出系统

### 考试定位

今年参考分布约 9 分，其中可能有 6 分计算。重点是可靠性、RAID、通道、DMA 与 Cache 一致性。

### 必会概念

- I/O 系统组成：I/O 设备、I/O 接口、I/O 驱动程序。
- I/O 性能：响应时间、吞吐率、连接特性、容量、CPU 打扰。
- 异步性、实时性、设备无关性。
- 可靠性、可用性、可信性。
- MTTF、MTTR、MTBF、失效率。
- RAID 0、1、2、3、4、5、10。
- 总线类型、总线仲裁。
- I/O 管理方式：程序查询、中断、DMA、通道。
- 通道处理机、字节多路通道、选择通道、数组多路通道。
- DMA 与虚拟存储器：物理 DMA、页钉住、虚拟 DMA。
- I/O 与 Cache 数据一致性。

### 必会公式

```text
部件失效率 = 1 / MTTF
系统失效率 = Σ(部件个数 × 部件失效率)
系统 MTTF = 1 / 系统失效率
可用性 = MTTF / (MTTF + MTTR)
MTBF = MTTF + MTTR
```

### 必会题型

- 给多个部件 MTTF，求系统 MTTF。
- 给 MTTF/MTTR，求可用性。
- 用 Amdahl 思想分析 CPU 改进但 I/O 不变时的总体性能。
- 比较 RAID 级别的性能、空间开销、容错能力。
- 简述通道处理机的工作过程。
- 判断 DMA 与虚拟存储器、Cache 一致性的冲突。

### 易错点

- 多部件串联系统的失效率相加，MTTF 不是简单相加。
- RAID 0 无冗余，不能容错。
- 写回 Cache 下，I/O 直接读主存可能读到旧数据。
- 通道处理机是小型专用 DMA 处理机，可与 CPU 并行执行通道程序。
