查证完毕，先给你结论，再给理由。

## 一、Articulated 3D 评测集：选 PartNet-Mobility 还是 Articraft-10K？

**结论：主测用 PartNet-Mobility，Articraft-10K 只做补充测试或训练数据，不要用它替代 PartNet-Mobility。**

理由：

| 维度     | PartNet-Mobility                                             | Articraft-10K                                                |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 规模     | 46 类 / ~2.3K                                                | 245 类 / >10K                                                |
| 标注性质 | **人工标注 GT**（part、joint type/origin/axis/limit）        | 生成数据，QC + 人工筛选，**不是人工逐例标注的 GT**           |
| 可比性   | 几乎所有 articulated 论文都报告过它的结果，baseline 齐全     | 没有任何其他方法报告过结果，无 baseline 可比                 |
| 划分惯例 | 有公认 split（SINGAPO 7 类、Real2Code 5 类、CAGE 6 类、ID/OOD） | 无公认 split                                                 |
| 质量     | 部分资产法线错误、结构简化（ArtLLM 论文专门做了修复）        | 经过 QC + 91.8% 保留率筛选，整体质量较新                     |
| 偏置风险 | 无（第三方数据）                                             | 与 Articraft 同源；测 Articraft 或类似 harness 方法时可能"自己考自己" |
| 适用场景 | **方法对比、模型有效性验证**                                 | 大规模泛化测试、OOD 覆盖、训练数据增强                       |

**实用建议**：

- 如果你的目的是**验证你的模型好不好、和已有方法比**：必须用 PartNet-Mobility，因为它是唯一有 GT 且 baseline 齐全的标准集。
- 如果你想测**大规模、多类别、OOD 泛化**：可以额外从 Articraft-10K 抽一个子集（比如每类 2–5 个），但要明确说明它是生成数据而非人工 GT，并且建议你**自己人工验证这个子集**再作为补充 benchmark。
- Articraft-10K 更合适的角色是**训练数据增强**（Articraft 论文自己就是这么用的：拿它训练 Particulate，再去 Lightwheel 上评测），而不是替代评测集。

## 二、静态 CAD 评测集：哪个最新、哪个开源且最新？

先纠正一下：我之前给你的静态 CAD 列表里的 **ACD 不是静态 CAD 数据集**。ACD 出自 S2O（Static to Openable Enhancement for Articulated 3D Objects, WACV 2026），是 articulated 数据集，不应放在静态 CAD 评测里。

**静态 CAD 常用开源评测集按时间排：**

| 数据集             | 发布时间      | 规模                                                         | 开源 | 说明                                                         |
| ------------------ | ------------- | ------------------------------------------------------------ | ---- | ------------------------------------------------------------ |
| ABC                | 2019          | 1M+ B-Rep 模型                                               | ✅    | 几何/逆向工程常用，不是 text-to-CAD                          |
| Fusion 360 Gallery | 2020          | 8,625 个带建模历史设计                                       | ✅    | reconstruction/segmentation 常用                             |
| DeepCAD Dataset    | ICCV 2021     | 178,238 个 sketch-extrude 序列                               | ✅    | 最经典，几乎所有序列生成方法都报它                           |
| CADPrompt          | ICLR 2025     | 200 个 text-prompt + 专家 CAD 代码 + STL/OBJ                 | ✅    | 小，但**专门为 text-to-CAD 设计**，是 CADCodeVerify 论文的 benchmark |
| **CADmium**        | **TMLR 2026** | HuggingFace 开源（含训练/验证/测试 split + 1.5B/3B/7B/14B 模型） | ✅    | **目前最新、且完全开源**的 text-driven sequential CAD benchmark |

**结论**：

- **最新且开源：CADmium**（TMLR 2026 年 1 月接收，arXiv 2507.09792；GitHub `chandar-lab/CADmium` + HuggingFace 数据集和模型）。它同时提供数据、模型和评测代码，是当前静态 CAD text-to-CAD 方向最合适的新基准。
- **规模最大、最经典：DeepCAD Dataset**（ICCV 2021，官方 GitHub 开源），虽然老，但 baseline 最多，做对比仍然绕不开。
- **CADPrompt**（ICLR 2025，GitHub `Kamel773/CAD_Code_Generation`）也开源，但只有 200 个样本，适合做小规模快速验证。

**建议组合**：
- 要**可比性**：DeepCAD（baseline 最多）
- 要**最新且开源**：CADmium（TMLR 2026，有官方评测和模型，最适合作为新的主 benchmark）
- 要**快速验证**：CADPrompt（小，200 个）

## 三、给你最终评测集选择清单

| 你的任务                                   | 首选评测集                               | 补充/备选                                     |
| ------------------------------------------ | ---------------------------------------- | --------------------------------------------- |
| Articulated 3D 生成（对比已有方法）        | **PartNet-Mobility**（有 GT + baseline） | Articraft-10K 子集（人工验证后测 OOD/多样性） |
| Articulated 3D 生成（大规模泛化/数据增强） | Articraft-10K（明确标注无人工 GT）       | PartNet-Mobility（抽 7 类做快速检查）         |
| 静态 CAD text-to-CAD                       | **CADmium**（TMLR 2026，最新开源）       | DeepCAD（baseline 多）、CADPrompt（快速小测） |
| 静态 CAD 逆向/重建                         | DeepCAD / Fusion 360 Gallery / ABC       | 按表示（B-Rep vs sequence）选择               |

一句话总结：**评测要看 GT + baseline，所以 articulated 主用 PartNet-Mobility；静态 CAD 最新开源的是 CADmium（TMLR 2026）。Articraft-10K 适合做训练数据和补充测试，不适合当唯一评测集。**
