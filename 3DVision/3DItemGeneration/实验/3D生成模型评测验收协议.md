# 3D 生成模型评测验收协议

> 版本：v1.0
> 适用范围：
> - **Articulated 3D 物体生成**（主评测集：PartNet-Mobility）
> - **静态 CAD 生成**（主评测集：DeepCAD；补充评测集：CADmium）
> 适用对象：agentic 3D 生成系统（含 Harness 架构）、端到端生成模型、其他任何输出 URDF / CAD 程序 / mesh 的生成方法。
> 本协议回答一个问题：**一个模型/系统生成的结果，到底该验收哪些指标、怎么算通过、怎么报告。**

---

## 0. 总览：验收分五层

无论 articulated 还是 static CAD，验收都按以下五层由低到高执行。低层不通过，高层指标无效。

| 层 | 验收内容 | 核心问题 |
|---|---|---|
| L1 可执行性 | 程序能跑、URDF 能解析、mesh 能加载 | 生成物是否有效 |
| L2 结构正确性 | part/link/joint/segment 数量与拓扑对不对 | 组成是否对 |
| L3 几何质量 | 形状像不像、尺寸对不对、表面质量如何 | 长得对不对 |
| L4 物理/拓扑有效性 | 碰撞、稳定、自相交、水密性、实体合法性 | 是否真的能用 |
| L5 语义与下游 | prompt 对齐、下游任务/仿真可用性 | 是否满足意图 |

**总成功定义**：单样本在 L1 通过的前提下，L2–L4 全部达标才算"成功"；L5 作为补充证据和开放任务的替代判据。

## 1. 通用评测规则（两部分通用）

### 1.1 失败处理规则（必须遵守）

| 情况 | 处理方式 |
|---|---|
| 程序执行失败 / URDF 解析失败 / JSON 非法 | Success=0；几何类指标记 worst-case（CD=√3 或数据集最大值，IoU=0，F1=0）；并在报告中单独列出失败数 |
| 生成结果与 GT 无法建立 part/loop 对应 | 结构类指标全部记 0，允许不参与几何类指标计算，但必须报告"无法对应样本数" |
| 指标需要水密 mesh 而 mesh 不水密 | 该样本只参与水密率统计，不参与 SD/DMCD/EECM 等需要水密前置的指标（CADmium 规则） |
| 禁止剔除失败样本后只报成功子集 | 除非同时报告有效子集的样本量与原始样本量 |

### 1.2 统计与报告规则

- 连续指标：报告 **均值 + 中位数 + 95% 置信区间**（CADmium 与 CADSmith 均采用此做法）。
- 二值指标：报告 **百分比 + 样本量**。
- 与 baseline 比较：做显著性检验，articulated 的 success rate 用 McNemar/配对检验；连续指标先做正态性检验再选 Welch t 或 Mann-Whitney U；二值指标用 Fisher 精确检验。p<0.05 才可宣称"优于"。
- 所有指标分 **ID（训练分布内）** 与 **OOD（训练分布外）** 两组分别报告。
- 报告必须包含 **失败案例数量与失败类型分布**（执行失败/结构错/几何差/物理非法/其他）。

### 1.3 基线要求

每个实验至少报告两条基线：
1. **SOTA 公开方法**（可比较性）；
2. **同 backbone 单次生成 / 去掉 agent 机制的简化版**（排除"底层模型强"的替代解释）。

## 2. Articulated 3D 物体生成验收（PartNet-Mobility）

### 2.1 数据集与 GT

| 项 | 说明 |
|---|---|
| 数据集 | PartNet-Mobility |
| 规模 | 46 类，约 2.3K 资产 |
| 划分建议 | 优先使用与基线论文一致的 split。建议至少报告：SINGAPO 7 类 split（Storage/Table/Refrigerator/Dishwasher/Oven/Washer/Microwave，77 对象）作为 ID；其余 39 类作为 OOD |
| GT 内容 | 每个 link 的 mesh、link 层级（parent-child）、joint type（revolute/prismatic/fixed）、joint origin（xyz）、joint axis、joint limit（lower/upper）、URDF 文件 |
| 输入形式 | 文本 prompt；或"参考图 + 文本"；必须与基线一致，且每类 ≥5 个 prompt（参考 Articraft） |

### 2.2 L1 可执行性验收

| 指标 | 定义 | 通过线 |
|---|---|---|
| **URDF 解析成功率（Exec%）** | 生成的 URDF 能被标准解析器（如 `urdfpy` / `yourdfpy` / ROS `urdf_parser`）成功加载，且引用的 mesh/材质文件存在 | ≥95%，目标 100% |
| **mesh 加载成功率** | 每个 link 的 visual/collision mesh 能被 trimesh/open3d 加载且非空 | ≥95% |

### 2.3 L2 结构正确性验收

先建立 **part 对应关系**：对预测 link 与 GT link 的 mesh 中心做匈牙利匹配（同 ArtLLM 协议）。固定 joint 按 ArtLLM 的处理方式：移除固定 joint 并把其父子 link 合并后再匹配。

| 指标 | 定义 | 通过线/参考 |
|---|---|---|
| **Part 数量准确率（Count Acc）** | 预测的非固定 joint link 数量与 GT 一致的比例 | 报告值，目标 ≥0.9 |
| **Part mIoU** | 匹配后逐点分割 mIoU（对 mesh 采样点云计算） | 报告值，对比 baseline |
| **Joint Type Acc** | 匹配后 joint type 一致的比例 | 报告值 |
| **Graph Acc** | 由 link 与 joint 构成的有向图（parent-child 结构）完全一致的比例 | 报告值 |
| **Joint Axis Err（弧度）** | 预测轴与 GT 轴的角度差，归一化到 [0, π] | 成功线 < 0.25 rad（Articulate-Anything 先例） |
| **Joint Origin Err（米）** | 预测 joint origin 与 GT 的欧氏距离 | 成功线 < 50 mm（Articulate-Anything 先例） |
| **Joint Limit IoU / Limit Err** | 预测限位范围与 GT 范围的 IoU（或绝对误差） | 报告值；revolute/prismatic 分开报 |

### 2.4 L3 几何质量验收

| 指标 | 定义 | 通过线 |
|---|---|---|
| **Part-level CD** | 建立 part 对应后，逐 part 计算 Chamfer Distance（10K 采样点，ICP 对齐） | 报告均值/中位数，对比 baseline |
| **Part-level F1@τ** | 距离阈值 τ 下的 F1；articulated 建议 τ 用归一化空间（与 baseline 一致） | 报告值 |
| **整体 RS-IoU** | 静止状态整体 mesh 的体素 IoU | 报告值 |

### 2.5 L4 物理与运动有效性验收（articulated 必做）

| 指标 | 定义 | 通过线 |
|---|---|---|
| **物理可执行性（Physical Executability）** | URDF 加载进 SAPIEN/Isaac Sim/MuJoCo 后，所有非固定 joint 可被驱动到指定角度/位移，无部件飞走、关节冻结、非物理行为（URDF-Anything 定义） | 报告值，目标 ≥90% |
| **自碰撞率（Self-collision ratio）** | 在全关节行程内采样 ≥10 个姿态，对每个姿态做 mesh 碰撞检测，存在非允许碰撞的比例 | ≤5% |
| **静止稳定率** | 放在地面/支撑面上，仿真 120 步后位移 <0.2m 且旋转 <8° 的比例（SAGE 定义） | ≥95% |
| **连接保持（可选，适合有 GT 运动范围时）** | 关节运动全程父子 link 连接区域距离不超过设定阈值（用户 Harness 已有能力） | 报告值 |

### 2.6 L5 语义与下游验收

| 项 | 方法 | 通过线 |
|---|---|---|
| **Prompt 对齐** | VLM-as-judge：3 个不同家族 VLM 独立评分（1–5，含关节运动 keyframe 渲染），报告 Krippendorff's α 与 ICC(2,3) | α>0.5，ICC>0.8 |
| **人类偏好** | pairwise 用户研究（建议 ≥100 人，总对比 ≥3000），报告 win rate + p 值 | win rate 显著 >50% |
| **机器人/仿真下游** | 在 Isaac Sim 中用 IK 控制机械臂与生成物体交互（如开抽屉/柜门），报告成功次数/任务数 | 报告值 |

### 2.7 复合成功判据（主指标）

> **单样本成功** 当且仅当同时满足：
> 1. Exec=通过（URDF 可解析）；
> 2. Count Acc=通过（非固定 link 数量一致）；
> 3. 每个非固定 joint：Type 正确 且 Axis Err<0.25rad 且 Origin Err<50mm；
> 4. Physical Executability=通过（可驱动且无自碰撞）。
>
> **主指标 = Success Rate = 成功样本数 / 总样本数。**

### 2.8 Agentic 过程指标（仅 agentic 系统报告）

| 指标 | 定义 | 参考线 |
|---|---|---|
| 平均迭代轮数 | 每个成功/失败样本的编译-测试循环次数 | 报告值，对比 baseline |
| 诊断 Agent 触发率 | 普通修复失败后进入诊断流程的比例 | 报告值 |
| Spec 版本数 | 每个任务平均 spec 修订次数 | 报告值 |
| 隐藏复核通过率 | 公开测试通过后，隐藏复核仍通过的比例 | ≥95% |
| 单样本成本/时间 | API cost、wall-clock | 报告值 |

## 3. 静态 CAD 生成验收（DeepCAD 为主，CADmium 补充）

### 3.1 数据集与 GT

| 项 | DeepCAD（主） | CADmium（补充） |
|---|---|---|
| 规模 | 178,238 个 sketch-extrude 序列 | train 118,299 / val 8,925 / test 8,046（继承 Text2CAD split） |
| GT 内容 | CAD command 序列（命令类型 + 参数）+ 可执行得到 mesh | 文本 prompt + 最小 JSON 格式 CAD history + 可执行得到 mesh |
| 输入 | 无条件 / 文本（Text2CAD 协议） | 文本描述 |
| 用途 | 序列准确性、与最多 baseline 比较 | 文本条件生成、拓扑/几何质量、最新开源基准 |
| 开源 | 官方 GitHub（ChrisWu1997/DeepCAD） | HuggingFace（chandar-lab/CADmium-ds）+ GitHub |

### 3.2 L1 可执行性验收

| 指标 | 定义 | 通过线 |
|---|---|---|
| **程序/序列有效性（Valid ratio / IR）** | 生成序列能通过 CAD kernel 执行并产生合法 solid/mesh；Invalidity Ratio = 失败比例（CADmium 的 IR） | IR 越低越好，报告值 |
| **JSON/程序解析成功率** | 输出格式可解析的比例 | ≥95% |

### 3.3 L2 结构正确性验收（序列 GT 可算，DeepCAD 核心）

| 指标 | 定义 | 通过线 |
|---|---|---|
| **Command Accuracy** | 生成序列与 GT 序列按位置/对齐后命令类型一致率 | 报告值 |
| **Parameter Accuracy** | 对齐后参数误差（连续参数量化后一致率或回归误差） | 报告值 |
| **Sequence-level Accuracy / APCS** | 整条序列命令与参数都正确才算对（参考 TransCAD 的 APCS/mAP 思路） | 报告值 |
| **Segment Error（SegE）** | 预测与 GT 的 segment/loop 数量差（缩放后的绝对值，CADmium 指标） | 报告值 |

### 3.4 L3 几何质量验收

| 指标 | 定义 | 通过线 |
|---|---|---|
| **Chamfer Distance（CD）** | 生成 mesh 与 GT mesh 的对称 Chamfer，10K 采样点，ICP 对齐 | 报告 **中位数**（CADmium 建议，避免异常值） |
| **F1@τ** | 距离阈值 τ 下，Hungarian 匹配 loop 后计算 | 报告值；τ 与 baseline 一致 |
| **体素 IoU** | 归一化或绝对空间（CADSmith 建议绝对空间 mm）体素 IoU | 报告值 |

### 3.5 L4 拓扑与实体有效性验收（静态 CAD 必做）

| 指标 | 定义 | 通过线 |
|---|---|---|
| **Watertight %** | 生成 mesh 水密（无边界边、无孔洞、2-manifold）的比例 | 报告值 |
| **Self-Intersection Ratio（SIR）** | 自相交面的比例（CADmium 指标） | 报告值，越低越好 |
| **Dangling Edge Length（DangEL）** | 被少于两个面共享的边总长度（CADmium 指标） | 报告值 |
| **Flux Enclosure Error（FluxEE）** | 封闭性通量误差（CADmium 指标） | 报告值 |
| **Euler Characteristic Match（EECM）** | 预测与 GT 的欧拉示性数 χ=V−E+F 是否一致（二值） | 报告值 |
| **Sphericity Discrepancy（SD）** | 预测与 GT 球度差异（仅水密样本计算） | 报告值 |
| **Discrete Mean Curvature Difference（DMCD）** | 离散平均曲率差异（仅水密样本计算） | 报告值 |
| **Solid validity** | B-Rep/STEP 在 OpenCASCADE 中为合法实体（无 open shell、自相交） | 报告值 |

### 3.6 L5 语义与下游验收

| 项 | 方法 | 通过线 |
|---|---|---|
| **文本对齐** | CLIP（渲染图 vs 文本）+ VLM 评分（3 个 VLM） | 报告值 |
| **LLM-as-judge（CADmium 协议）** | 用 Gemma-3 12B + Mistral Small 3.2 24B 等对描述质量/视觉忠实度/完整性打分 | 报告值 |
| **可制造性（可选）** | 3D 打印 / 制造约束检查 | 报告值 |

### 3.7 复合成功判据（主指标）

> **单样本成功** 当且仅当同时满足：
> 1. 序列/程序有效（kernel 执行成功，IR=0 计入成功）；
> 2. 生成 mesh 水密；
> 3. SIR=0（无自相交）；
> 4. CD（中位数）在 baseline 的 ±1 个 MAD 内或绝对阈值内（阈值用小规模人工标定确定）。
>
> **主指标 = Success Rate（或 1−IR 与各分项的组合报告）**。

## 4. 验收执行流程

```
Step 0  准备数据集 + 确认 split + 确认 GT 可解析
Step 1  运行模型生成全部测试样本，记录元数据（trace/迭代/成本/时间）
Step 2  L1 可执行性检查（先淘汰执行失败样本）
Step 3  L2 结构正确性（part/loop 对应 + joint/segment 指标）
Step 4  L3 几何质量（CD/F1/IoU）
Step 5  L4 物理/拓扑（仿真、碰撞、水密、自相交）
Step 6  L5 语义与下游（VLM judge + 人类研究 + 仿真/打印）
Step 7  统计报告 + 失败案例分类 + 消融归因
```

每步输出一张表，最终汇总到第 5 节模板。

## 6. 一句话备忘

> **Articulated 主看复合 Success Rate（exec + 结构 + 关节参数 + 物理可执行）；静态 CAD 主看 Valid + 水密 + 自相交 + CD median，并用 CADmium 拓扑指标补足；所有结论必须有失败处理和显著性检验。**
