## A. 静态 CAD（history / program / B-Rep）

### A1. CSGNet — CVPR 2018
- 图像/体素 → CSG program（primitive + Boolean）
- CNN+RNN 自回归；表示=CSG 构造树
- 地位：可解释形状程序的开端
- 关系：前身是无监督体素解析；后继 UCSG-Net、DeepCAD
- 短板：只能做简单 primitive 组合，不是工业 CAD

### A2. UCSG-Net — NeurIPS 2020
- raster/voxel → CSG tree
- 无监督、可微 CSG 重建
- 地位：让 CSG 恢复不需要监督标签
- 短板：表达力和精度有限，后被 sketch-extrude 线超越

### A3. DeepCAD — ICCV 2021
- CAD construction sequence ↔ latent
- Transformer 自回归；表示=sketch-extrude history
- 地位：CAD history 表示学习与数据集基石
- 关系：继承 CSG 思想；启发 SkexGen / Text2CAD / GenCAD
- 短板：无条件为主，几何是坐标序列不是约束

### A4. Vitruvion — ICLR 2022
- 图像/草图 → 2D primitive + constraint graph
- 模型只生成约束，CAD solver 求坐标
- 地位：把"设计意图"表达为约束图
- 关系：区别于 DeepCAD 直接坐标；思想延续到程序+solver 路线
- 短板：只有 2D sketch，不是 3D 实体

### A5. SkexGen — ICML 2022
- codebook → sketch-extrude sequence
- 自回归；topology / geometry / extrusion 三 codebook 解耦
- 地位：可控 CAD sequence 生成的中间节点
- 短板：无条件/控制有限，不涉及文本和图像

### A6. SolidGen — TMLR 2023
- noise/image/voxel → B-Rep（vertices/edges/faces）
- 自回归实体图；B-Rep-first
- 地位：直接生成 B-Rep、不依赖 history 的代表
- 关系：接 SolidWorks/Onshape B-Rep 数据；BrepGen 用扩散进一步做 watertight
- 短板：没有 design history，可编辑性弱

### A7. SECAD-Net — CVPR 2023
- occupancy/voxel → sketch-extrude
- 自监督，不需要 CAD history 标注
- 地位：降低 history 数据门槛的桥
- 短板：重建精度与复杂度低于有监督路线

### A8. BrepGen — SIGGRAPH 2024
- noise/partial B-Rep → watertight B-Rep
- hierarchical latent tree + diffusion；面可含 plane/cylinder/cone/sphere/torus/Bezier/NURBS
- 地位：B-Rep 扩散生成的基准工作
- 关系：继承 SolidGen；被 DTGBrepGen / HoLa / AutoBrep / DualBrep 对标
- 短板：面几何曾用 UV-grid（NeuroNURBS 批评），编辑意图弱

### A9. Text2CAD — NeurIPS 2024 Spotlight
- text → CAD command sequence
- BERT 文本编码 + 自回归 Transformer
- 地位：语言条件 CAD history 的早期代表
- 关系：站在 DeepCAD 序列表示上
- 短板：sketch-extrude 为主，复杂自由曲面有限

### A10. TransCAD — ECCV 2024
- point cloud → loop-extrusion sequence
- hierarchical Transformer + loop refiner
- 地位：点云逆向 CAD history 的单阶段代表
- 关系：与 Point2CAD 并列为逆向两条路线（history-first vs B-Rep-first）
- 短板：依赖 CAD 标注，真实扫描泛化有限

### A11. STEP-LLM — DATE 2026
- text → STEP entities
- LLM + DFS reserialization + RAG-SFT + GRPO
- 地位：直接生成工业交换格式的 LLM 路线
- 短板：STEP 图复杂度高，物理验证仍弱

### A12. CADSmith — arXiv 2026
- text → CadQuery → CAD solid
- Planner/Coder/Executor/Validator/Refiner；OCCT 几何测量 + VLM judge
- 地位：agentic 静态 CAD 的代表
- 关系：与 Arko-T / Zero-to-CAD 同代；你的工作是把它搬到 articulated + 可信 Harness
- 短板：静态件，无 spec/test 冻结与运动学验证

### A13. Arko-T — arXiv 2026
- text → Build123d program → solid
- 结构化 design state + 执行过滤，保留参数化 construction intent
- 地位：强调"程序保留设计意图"的 foundation-model 路线
- 短板：静态 CAD，无装配/关节语义

## B. 曲面 / mesh / B-Rep 几何

### B1. DeepSDF — CVPR 2019
- shape → continuous SDF
- autodecoder + MLP 隐式场
- 地位：隐式连续曲面表示奠基
- 关系：继承 Occupancy/IM-NET 谱系；启发 SDF-VAE（TripoSG）等
- 短板：SDF 要求封闭有内外，对开放/非流形不好

### B2. ParSeNet — CVPR 2020
- point cloud → 参数曲面（平面/圆柱/圆锥/B-spline）
- 分解 + 参数拟合
- 地位：点云到参数曲面的早期代表作
- 关系：前接区域分割/拟合；ComplexGen 把拓扑一起做全
- 短板：只拟合曲面，不重建完整合法 B-Rep

### B3. NURBS-Diff — CAD 2022
- NURBS → 可微曲面模块
- 自动微分 NURBS 求值
- 地位：让 NURBS 可被学习优化
- 关系：后续 NeuroNURBS / NURBGen 的几何基础之一
- 短板：模块级工作，不是生成系统

### B4. ComplexGen — SIGGRAPH 2022
- point cloud → B-Rep chain complex（vertices/edges/faces + incidence）
- sparse CNN 编码 + tri-path Transformer + 全局优化
- 地位：几何+拓扑联合重建 B-Rep 的代表
- 关系：继承 ParSeNet；与 Point2CAD 同问题不同路线
- 短板：无 history，重建复杂度有限

### B5. Surf-D — ECCV 2024
- noise/条件 → 任意拓扑曲面
- UDF + point-based AE（DGCNN 编码 + CBN-MLP 解码）+ latent diffusion（DDPM）
- 地位：任意拓扑高质量曲面生成
- 关系：用 UDF 突破 SDF 封闭假设；启发了后续 UDF 生成
- 短板：视觉几何而非 CAD 实体

### B6. Point2CAD — CVPR 2024 Spotlight
- point cloud → CAD B-Rep
- 逆向工程；重建参数曲面实体
- 地位：真实扫描到 CAD 的逆向代表
- 关系：对标 ComplexGen；后续 BrepGaussian 从多视图做类似事
- 短板：观测不完整，语义歧义

### B7. NeuroNURBS — arXiv 2024
- B-Rep → 原生 NURBS 参数表示
- NURBS 参数 autoencoder，替代 UV-grid 点采样
- 地位：曲面表示效率/质量升级
- 关系：改进 BrepGen 的面表示（FID 30.04→27.24）
- 短板：表示模块，不是完整生成系统

### B8. HoLa — SIGGRAPH 2025
- text/image/point/sketch → B-Rep
- holistic latent + diffusion
- 地位：多模态条件 B-Rep 生成
- 关系：继承 BrepGen；与 DTGBrepGen/AutoBrep 同代竞争
- 短板：训练数据与拓扑复杂度受限

### B9. TripoSG — arXiv 2025
- image（或 scribble+text）→ mesh
- SDF-VAE + 大规模 Rectified Flow Transformer
- 地位：通用高保真 shape prior
- 关系：Flow Matching 进入 3D 的标志；FreeArt3D 等复用其 prior
- 短板：mesh-only，无 CAD/装配语义

### B10. TRELLIS.2 — CVPR 2026
- image → PBR-textured 3D asset
- O-Voxel + compact VAE + 4B Conditional Flow Matching
- 地位：高保真视觉资产生成
- 短板：仍然是视觉资产，不适合直接制造/仿真编辑

### B11. Flatten The Complex — SIGGRAPH 2026
- noise/image/point → B-Rep
- compositional k-cell particles + Rectified Flow Transformer，联合生成拓扑与几何
- 地位：Flow Matching 进入 B-Rep 的标志之一
- 关系：与 DualBrep 并列 2026 B-Rep 双前锋
- 短板：很新，基准与开源生态未稳

### B12. DualBrep — SIGGRAPH 2026
- point cloud/image/noise → watertight B-Rep/STEP
- SDF+UDF dual fields + latent Flow Matching + neural rebuilder
- 地位：Autodesk 的 B-Rep 生成新基线
- 短板：训练成本高，design history 仍弱

### B13. B-repLer — SIGGRAPH 2026
- source B-Rep + text → edited B-Rep
- mLLM 规划 edit latent + Flow Matching 编辑
- 地位：语言引导的自由曲面 CAD 编辑
- 短板：编辑任务，不是从零生成完整装配

## C. Articulated object（part/joint/URDF/agent）

### C1. NAP — NeurIPS 2023
- graph/noise → articulated object（part geometry + joint kinematic edges）
- articulation graph/tree diffusion
- 地位：articulated prior 的第一块基石
- 关系：证明几何与运动结构必须联合建模
- 短板：无语言/图像条件，几何粗

### C2. Articulate-Anything — ICLR 2025
- text/image/video → Python/URDF
- mesh retrieval + link placement + joint prediction；VLM actor–critic
- 地位：检索式关节化 + VLM 闭环
- 短板：依赖资产库，不生成新几何

### C3. ArtFormer — CVPR 2025
- text/image → part tree + mesh
- tree tokens + geometry latent + joint relation；Transformer+SDF prior
- 地位：可控 articulated 生成
- 短板：训练复杂，物理验证弱

### C4. ATOP — arXiv 2025
- static segmented mesh + motion text → motion parameters
- motion personalization + multi-view generation + differentiable rendering
- 地位：让已有静态部件可动
- 短板：需要分割好的静态 mesh

### C5. FreeArt3D — SIGGRAPH Asia 2025
- multi-state RGB → textured articulated mesh
- occupancy hash grids + frozen TRELLIS + per-instance optimization
- 地位：训练无关的观测重建
- 短板：逐实例优化，慢，难批量

### C6. URDF-Anything — NeurIPS 2025
- point cloud + text → segmentation + URDF
- 3D MLLM 自回归生成 link-joint JSON + [SEG] token
- 地位：观测到 URDF 的代表
- 关系：继承 NAP 结构思想；启发 ArtLLM
- 短板：几何来自点云分割，不是生成新 CAD

### C7. ArticFlow — arXiv 2025
- action + noise → mechanism point sets
- 两阶段 Flow Matching（latent shape prior + action-conditioned point flow）
- 地位：动作条件机构生成
- 短板：点集形态，未到 CAD/URDF 工业级

### C8. SPARK — CVPR 2026 Oral
- single RGB → part meshes + URDF
- VLM part/joint guidance + Rectified Flow 生成 part mesh latents + FK/render refine
- 地位：单图到 sim-ready articulated 资产
- 短板：重建任务，单图运动学本质有歧义

### C9. ArtLLM — CVPR 2026
- point cloud → articulation blueprint → mesh
- 3D LLM 先预测 part/joint layout，XPart 再生成部件几何
- 地位：结构先于几何的两阶段
- 短板：依赖点云输入

### C10. LAM — CVPR 2026
- text → link hierarchy + geometry/joint code
- Link Designer + Geometry/Articulation Coder + VLM Checker/Fixer
- 地位：文本到 articulated 的 code-first 系统
- 短板：视觉检查不够精确，缺少不可篡改的硬验证

### C11. ArtiCAD — arXiv 2026
- text/image → FreeCAD parts + typed joints + URDF
- Design/Generation/Assembly/Review agents；Connector contract
- 地位：connector-first 装配生成
- 短板：无开源代码，验证粒度与可信度待工程化

### C12. Articraft — arXiv 2026
- text/image → model.py + mesh/URDF/tests
- 受限 SDK + compile/probe/test harness + LLM repair
- 地位：可扩展 agentic articulated 资产生成
- 短板：视觉反馈弱，没有 spec/test 冻结与归因修复——**这是你的切入点**

## D. 8字段速答示例（照这个标准练）

问：NURBGen
答：
1. text → NURBS/analytic JSON → B-Rep
2. 表示：面级 NURBS + analytic primitive 混合
3. 范式：LLM（Qwen3-4B LoRA）结构化生成，非扩散
4. AAAI 2026（arXiv 2025）
5. 文本条件 CAD 生成，解决复杂曲面参数生成
6. 前作：NeuroNURBS（NURBS 表示）、Text2CAD（文本条件）
7. 后继/同代：STEP-LLM、DualBrep 在抢 B-Rep 表示权
8. 短板：依赖 LLM 参数精度，单面级生成，装配语义弱
